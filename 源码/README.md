# 互动答题卡 · Anki 插件

在复习界面直接作答 **选择题 / 判断题 / 填空题**：

- 点「**不知道**」→ 直接记为 **重来**
- **答错** → 直接记为 **重来**（不给选 困难/良好/简单 的机会）
- **答对** → 自己挑 **困难 / 良好 / 简单**

菜单栏 **工具 → 互动答题卡：设置与统计…** 可以改设置、看每张卡片的作答统计。

桌面版 Anki 专用（依赖 Anki 的桌面 Python 接口，AnkiDroid / AnkiMobile 不支持）。

---

## 怎么用

插件会在启动时自动创建三个题型，**每种题型各自独立**，字段也各自独立：

| 题型 | 用途 | 字段 |
| --- | --- | --- |
| **互动答题卡·选择题** | 单选 / 多选 | 题目、选项、解析、解题技巧、来源、知识点 |
| **互动答题卡·判断题** | 对 / 错 | 题目、解析、解题技巧、来源、知识点（对/错由勾选框决定） |
| **互动答题卡·填空** | 原生填空（`{{c1::答案}}`，一个空一张卡） | 题目、解析、解题技巧、来源、知识点 |

1. 打开 **工具 → 互动答题卡：设置与统计…**，在「设置」页底部点 **生成示例卡片**（三个题型各一张）
2. 去「答题卡示例」卡组复习一次，先感受一下
3. 之后自己加卡片：**添加** → 右上角选题型 → 填字段

> 两个旧东西已经删掉了：**「类型」字段**（题型各自独立，不需要再猜）和旧的**「互动答题卡」通用题型**
> （启动时会自动清理；如果里面还有你自己写的笔记，会保留不删，并在调试日志里提示）。

## 字段怎么填

| 字段 | 说明 |
| --- | --- |
| `题目` | 题干，支持富文本、图片、公式（MathJax） |
| `选项` | 选择题的选项。编辑器里是一行一个输入框 + 右侧「正确」勾选框；存到字段里时长这样：`*李白`（行首 `*` = 正确答案） |
| `解析` | 答完显示的解释 |
| `解题技巧` | 答完显示的做题思路 / 技巧，可选 |
| `来源` | 出处，可选 |
| `知识点` | 一个链接（或 Anki 搜索式），答完题后卡片上出现「相关知识点」按钮，一点跳过去。写法见下面「相关知识点」 |

> 判断题内部还有一个 `答案` 字段（存「对 / 错」），但**编辑器里看不到它**——你只会看到那个勾选框。
> 选择题没有这个字段：正误直接标在选项行里。

### 选择题（题型「互动答题卡·选择题」）

`选项` 里一行一个，行首 `*`（也支持 `+`、`√`、`✓`）标出正确项：

```
*A. 李白
B. 杜甫
C. 白居易
```

- 只有一个 `*` → **单选**，点一下选项立刻判分
- 两个或更多 `*` → **多选**，选完点「提交答案」，默认必须**全对**才算对

行首的 `A.` `B、` `C)` 会自动去掉，变成选项前面的圆形标记。

也可以把正确项写在 `答案` 字段里（`B` 或 `AC`），此时 `选项` 里不用打 `*`。

### 判断题（题型「互动答题卡·判断题」）

题型选 **互动答题卡·判断题**。`题目` 写陈述句，答案用**勾选框**给：

- 勾上「这题是正确的」= **对**
- 不勾 = **错**

编辑器里看不到 `答案` 字段（它藏在后面存「对 / 错」），也不需要手打字。

## 编辑器里怎么填（重点）

选了这个题型之后，编辑器**直接换成好用的控件**（不是弹窗，就在字段位置）：

### 选择题

原来的「选项」文本框会变成一个**逐行的选项编辑器**：

```
选项（一行一个，右侧勾选正确答案）
[ 李白            ] [✓ 正确] [×]
[ 杜甫            ] [ 正确] [×]
[ 白居易          ] [ 正确] [×]
[＋ 添加选项]
```

- 每个选项**一个独立输入框**，右边一个**「正确」勾选框**——不用手打 `*`，答案不会和选项错位
- 勾 1 个 = **单选**（点一下选项立刻判分）；勾 2 个以上 = **多选**（选完点提交，全对才算对）
- 增删行：点 `[＋ 添加选项]`，或把光标放在某一行按 **Enter** 在它下面插一行；空行按 **Backspace** 删掉；行尾 `[×]` 也是删
- **Alt + ↑ / ↓** 调整这一行的上下顺序
- **Alt + 数字** = 勾选 / 取消第 N 行的「正确」
- 直接把整段选项粘进任意一行，会自动按行拆成多个选项
- 下面一行实时状态写着「✅ 识别为【单选】/【多选】」或「⚠ 还没勾选正确答案」

### 判断题

「答案」文本框变成一个**勾选框**：

```
[✓] 这题是正确的          当前：对
```

勾上 = 对，不勾 = 错，旁边写着当前值。再也不用手打「对 / 错」。

### 填空题

显示一行状态：`共 3 个空 → 3 张卡`（没写 `{{c1::}}` 会提示）。挖空还是用 Anki 原生的工具栏按钮 / `Ctrl+Shift+C`。

> 加选项就在选项区下面点 **[＋ 添加选项]**，或者在最后一行按 Enter。

### 填空（原生 cloze，推荐）

题型「**互动答题卡·填空**」用起来跟 Anki 自带的填空题完全一样：

```
题目：中国的首都是{{c1::北京}}，最大的城市是{{c2::上海}}。
```

→ 生成 **2 张卡**：第 1 张考「北京」，第 2 张考「上海」。

- 题目里写 `{{c1::答案}}`、`{{c2::答案}}`……**一个 c 号出一张卡**（同一个 c 号出现多次算一张卡）
- 编辑器工具栏上的**挖空按钮**、快捷键 **`Ctrl+Shift+C`** 都能直接用（这是原生 cloze 题型才有的待遇）
- 可以写提示：`{{c1::北京::中国首都}}`
- 复习时当前那个空位变成输入框，其它空位按 Anki 原生规则直接显示出来；判分、评级、统计规则跟别的题型一样
- 字段只有 5 个：`题目`、`解析`、`解题技巧`、`来源`、`知识点`

想改一个已有题型（比如草稿本上的单卡填空）为原生填空：**卡片浏览器 → 选中笔记 → 更改笔记模板 → 互动答题卡·填空**。

## 解题技巧：一键用同标签卡片的技巧

「解题技巧」字段下面多了一个 **[⚡ 用同标签卡片的技巧]** 按钮：

1. 先给这张卡加标签（比如 `唐诗`、`宋词`）
2. 点按钮 → 插件去翻**同标签、且写了「解题技巧」**的其他卡片
3. 只找到一条就直接填进去；多条会列出候选（按共同标签数排序，带题目和标签），点 **[用这条]** 选一条

标签框里刚敲、还没提交的标签也会一起算。同一个知识点写一次技巧，后面的卡一键复用。

## 相关知识点

字段 `知识点`（三个题型都有）里写一行，答完题后卡片上出现 **[📚 相关知识点：…]** 按钮：

```
https://zh.wikipedia.org/wiki/静夜思          ← 网址：交给系统浏览器
唐诗格律 -> anki:search:tag:唐诗               ← 「标题 -> 目标」
anki:deck:复习::唐诗                          ← 搜这个牌组
anki:note:1699999999999                      ← 直接定位这张笔记
tag:唐诗                                      ← 不带前缀的，直接当 Anki 搜索式
```

- 目标是网址 → 系统浏览器打开；其它 → 在 **Anki 卡片浏览器**里按这个搜索式搜出来
- 只写目标时，按钮文字就是目标本身；想要好看点的按钮就写 `标题 -> 目标`
- 答案面上也有这个按钮；手机上（没有插件）网页链接照样能点，搜索式会显示成「在 Anki 里搜：xxx」
- 编辑器里「知识点」下面有预览行和 **[试打开]**：制卡时点一下就知道链接对不对

## 答题界面

答对之后：

```
✅ 回答正确
正确答案：A. 李白
[ 困难 Hard ]  [ 良好 Good ]  [ 简单 Easy ]
```

答错或点"不知道"之后：

```
❌ 回答错误 —— 这题记为「重来」
正确答案：A. 李白
解析：……
解题技巧：……
[ 继续（记为重来） ]
```

在"记为重来"的状态下，即使你按键盘上的 `3`（良好）或点底部工具栏的「良好」，插件也会**强制记成重来**。

「解析」和「解题技巧」是一起出现的：答错时都会显示；答对时是否显示由配置项
`reveal_explanation_on_correct` 决定（默认显示）。背面（按空格翻过去的那一面）永远能看到。

多选漏选（如果开了「漏选记困难」）时：

```
⚠️ 漏选 —— 这题只能记为「困难」
[ 困难 Hard ]  [ 还是重来 Again ]
```

## 设置与统计窗口

**工具 → 互动答题卡：设置与统计…**

### 设置页

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 记录作答明细 | 开 | 统计功能的总开关；关掉后不再收集新数据，已有记录保留 |
| 明细保留天数 | 0 | 0 = 永久保留；大于 0 时超期记录自动清理 |
| 答题时显示计时 | 关 | 卡片右上角显示本题已用时间。不论开关如何，统计里的"平均用时"都会记录 |
| 多选漏选记「困难」 | 关 | 开启后，多选漏选（但没选错）可以记为困难，仍然不能记 良好 / 简单 |

底部还有两个兜底按钮：**创建 / 更新题型模板**、**生成 3 张示例卡片**（题型模板其实每次启动 Anki 都会自动更新）。

> 其余选项（答错后是否先显示答案、打乱选项、填空忽略标点等）在
> **工具 → 插件 → 互动答题卡 → 配置** 里，两边改的是同一份配置。

### 统计页

一张**卡片级统计表**，支持组合筛选：

| 筛选项 | 说明 |
| --- | --- |
| 牌组 | 选中某个牌组时**包含它的子牌组** |
| 题型 | 单选 / 多选 / 判断 / 填空 |
| 标签 | 集合里的标签（可直接输入） |
| 时间 | 全部 / 近 7 天 / 近 30 天 / 近 90 天 |
| 关键词 | 题目文字包含 |

表格列：题目、牌组、题型、作答次数、答错次数、正确率、**难度**、Anki 难易度、平均用时、最后作答。

**排序**（默认按难度高 → 低）：

- `难度 高 → 低`：先做错、反复做错的排前面
- `难度 低 → 高`
- `Anki 难易度 低 → 高`：按 Anki 自己的 ease factor 排

「难度」= 平滑后的错误率 `(答错次数 + 0.5) / (作答次数 + 1)`，避免"只做过一次刚好做错"直接排到第一。

表格上方一行会显示当前筛选条件下的卡片数、总作答次数、正确率和平均用时。右下角有 **清空统计** 按钮（只清当前用户配置的记录）。

> 只有在答题界面里真正作答过的卡片才会被记录（点选项、点提交、点不知道都算）。
> 直接按空格翻到背面的不算。

## 数据与限制

- 统计数据库：`addons21/interactive_quiz/user_files/stats.db`（SQLite，按用户配置分开存）
- **自动评级只在桌面版有效**；手机 / AnkiWeb 上会切到「手机模式」（见下）
- 「创建 / 更新题型模板」会**覆盖**三个题型的模板和样式，改过模板的话先备份
- 旧笔记不会自动变成 cloze 题型：新建笔记时选「互动答题卡·填空」，或用「更改笔记模板」把它转过去
- 想删干净：工具 → 插件 → 删除本插件，再删掉三个「互动答题卡·*」题型和 `user_files` 目录

## 手机上怎么用

卡片会正常同步到手机，**手机上照样能自测**，只是评级要自己按一下：

1. 选项照样点、填空照样填，当场就能看到「✅ 回答正确 / ❌ 回答错误 + 正确答案 + 解析」
2. 判完之后卡片下方会提示：**点「显示答案」，再按 1 重来 / 2 困难 / 3 良好 / 4 简单**
3. 排程由 Anki 自己按你选的评级算，和电脑上一样

判断依据是「卡片里有没有桌面插件注入的配置」：桌面有 → 自动评级（答错强制重来）；手机 / AnkiWeb 没有 → 手机模式，不假装能评级，也不会把按钮变灰卡住。

手机上**制卡**也照常：字段就是纯文本，选项行首写 `*` 就是正确项；判断题的 `答案` 字段在手机上会露出来，填「对 / 错」即可（电脑上那个勾选框只在桌面编辑器里出现）。
