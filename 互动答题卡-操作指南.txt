1. 这是什么
----------------------------------------------------------
装了它之后，复习界面不再是"看正面、翻背面"，而是直接做题：

  · 点「不知道」        -> 直接记为【重来】
  · 答错                -> 直接记为【重来】
  · 答对                -> 自己挑【困难 / 良好 / 简单】

答错或点「不知道」之后，就算你按键盘 3 或点底部工具栏的
「良好」，插件也会强制记成「重来」，跑不掉。

电脑版（Windows / macOS / Linux）功能最全：答错自动记「重来」。
手机版（AnkiDroid / AnkiMobile）也能刷这些卡，见第 6 节最后一问。


----------------------------------------------------------
2. 第一次使用
----------------------------------------------------------
插件启动时会自动创建三个题型，每种题型各自独立，一般不用管它们：

    互动答题卡·选择题   单选 / 多选
    互动答题卡·判断题   对 / 错
    互动答题卡·填空     原生填空（一个空出一张卡）

想先体验一下：
  [工具] -> [互动答题卡：设置与统计…]
  在「设置」页底部点 [生成示例卡片]（三个题型各写一张）
  然后去「答题卡示例」卡组复习一次。

想自己加题目：
  1) 点 [添加]
  2) 右上角选出题型：选择题用「互动答题卡·选择题」，
     判断题用「互动答题卡·判断题」，填空用「互动答题卡·填空」
  3) 填字段（选项直接勾选框，见 3.4）

工具菜单里只有一项：
  [工具] -> [互动答题卡：设置与统计…]


----------------------------------------------------------
3. 三种题型怎么录入
----------------------------------------------------------
插件管三个题型，一个题型只干一件事，字段也各管各的：

    互动答题卡·选择题   题目    选项    解析    解题技巧    来源    知识点
    互动答题卡·判断题   题目    解析    解题技巧    来源    知识点
    互动答题卡·填空     题目    解析    解题技巧    来源    知识点

1.1.3 起三个题型都**没有「答案」字段**了：
  · 选择题：正误直接标在选项行里（行首的 *）
  · 判断题：勾选框会把 对/错 写成题目末尾的一段隐藏标记
    （卡片上看不见，长这样：题干<!--iq-tf:对-->）
  · 填空题：答案写在题目里的 {{c1::}} 里

「解题技巧」可以一键复用同标签卡片的写法（见 3.5）；
「知识点」里一行一条「标签 -> 链接」，答完题后点标签就跳过去（见 3.6）。

（以前那个用来指定题型的「类型」字段、还有老的通用题型
「互动答题卡」，都已经删掉了。）

下面 3.4 讲编辑器里的勾选式填写方式。


3.1 选择题（题型：互动答题卡·选择题）
----------------------------------------------------------
编辑器里直接勾选（见 3.4）：每行一个选项，右侧勾上就是
正确答案。下面这种写法是它存到字段里的样子，知道就行：

    选项：*A. 李白
          B. 杜甫
          C. 白居易

  · 只有一个 *  -> 单选，点一下选项立刻判分
  · 两个或更多 * -> 多选，选完点「提交答案」，默认必须全对
                    才算对

行首的 A.  B、  C)  这类序号会自动去掉，变成选项前面的
圆圈标记，方便和「答案」对应。

1.1.3 起没有「答案」字段可写了：正误就在行首的 * 里，
一行都不打 * 的话，这张卡不会被判分（当普通卡片看）。


3.2 判断题（题型：互动答题卡·判断题）
----------------------------------------------------------
编辑器里只有一个勾选框：勾上 = 对，不勾 = 错（见 3.4）。
它会把 对 / 错 写成题目末尾的一段隐藏标记：

    题目：太阳从西边升起。<!--iq-tf:错-->

这段标记在卡片上看不见，也不影响搜索和卷面；万一被手工删掉，
插件下次启动 Anki 时会自动补回来。

认这些写法： 对 错 正确 错误 是 否 真 假
             √ × ✓ ✗ T F True False

界面上会出现「正确 / 对」「错误 / 错」两个按钮，点一下即判分。


（「解析」「解题技巧」「来源」是可选字段，答完会显示出来。
「解题技巧」和「解析」一样：答错一定显示，答对时看配置。）


3.3 原生填空（题型：互动答题卡·填空，跟 Anki 自带填空一样）
----------------------------------------------------------
用另一个题型「互动答题卡·填空」，制卡方式跟 Anki 原生填空
完全一致：

    题目：中国的首都是{{c1::北京}}，最大的城市是{{c2::上海}}。

  · 题目里写几个不同的 c 号，就出几张卡（上面这条出 2 张：
    一张考「北京」，一张考「上海」）
  · 同一个 c 号写两次，算同一张卡
  · 编辑器工具栏上的「挖空」按钮、快捷键 Ctrl+Shift+C 都能
    直接用，这才是原生填空的手感
  · 想给提示：{{c1::北京::中国首都}}
  · 这个题型只有四个字段：题目、解析、解题技巧、来源

复习的时候：当前那个空位变成输入框，其余空位按 Anki 原生
规则直接显示出来；判分和评级规则跟别的题型完全一样
（答错、点「不知道」一律记「重来」）。

旧版笔记（以前那种在「题目」里写 {{1}} 的单卡填空）想变成
原生填空：卡片浏览器里选中笔记 -> [更改笔记模板] ->
「互动答题卡·填空」，再把题目改成 {{c1::答案}} 的写法。


3.4 编辑器里怎么填（重点）
----------------------------------------------------------
选好题型之后，编辑器会直接把字段换成好用的控件（不是弹窗）：

【选择题】原来的「选项」文本框变成一个「一行一个选项」的
编辑器：

    选项（一行一个，右侧勾选正确答案）
    [ 李白            ] [✓ 正确] [×]
    [ 杜甫            ] [ 正确] [×]
    [ 白居易          ] [ 正确] [×]
    [＋ 添加选项]

  · 每个选项一个独立输入框，右边一个「正确」勾选框——
    不用手打 *，答案也不会和选项错位
  · 勾 1 个 = 单选；勾 2 个以上 = 多选
  · 增删行：[＋ 添加选项]，或在某一行按 Enter 在下面插一行；
    空行按 Backspace 删掉；行尾 [×] 也是删
  · Alt+↑ / Alt+↓  调整这一行的上下顺序
  · Alt+数字       勾选 / 取消第 N 行的「正确」
  · 把整段选项直接粘进任意一行，会自动按行拆成多个选项
  · 下面一行实时写着「✅ 识别为【单选】/【多选】」或者
    「⚠ 还没勾选正确答案」

【判断题】题目下面多一个勾选框：

    [✓] 这题是正确的      当前：对

勾上 = 对，不勾 = 错，旁边写着当前值，不用手打任何东西。

【填空题】显示一行状态：共 3 个空 → 3 张卡（没写 {{c1::}}
会提示）。挖空还是用 Anki 原生的工具栏按钮 / Ctrl+Shift+C。

3.5 解题技巧：一键用同标签卡片的技巧
----------------------------------------------------------
「解题技巧」字段下面有一个按钮：

    [⚡ 用同标签卡片的技巧]  找到 3 条，选一条：

先给这张卡加标签（编辑器左下角的标签框，比如 唐诗），再点这个
按钮，插件就会去找「同标签、并且写过解题技巧」的其他卡片，弹出
候选列表：

    [用这条]  先看选项，再想朝代
              🏷 唐诗 · 宋词
    [用这条]  遇到判断题先反过来读一遍
              🏷 唐诗

  · 候选里只显示技巧正文和共同标签，不再显示题目
  · 文字一样的技巧只出现一条（空格、换行不同也算同一条），
    留的是排在最前面的那张卡
  · 点哪一行前面的 [用这条]，就把那条技巧填进「解题技巧」
  · 这张卡还没标签 → 提示你先去加标签
  · 同标签的卡片都没写过技巧 → 也会明确告诉你

标签框里刚敲、还没按回车的标签也算数。同一个知识点写一次技巧，
后面同类卡片一键复用就行。

3.6 知识点：答完题点标签跳过去
----------------------------------------------------------
「知识点」字段（三个题型都有）里一行写一条「标签 -> 链接」，
答完题后卡片上就会出现一排标签，点哪个标签跳哪个链接：

    📚 相关知识点
    [ 唐诗 ]  [ 宋词 ]

写法（一行一条，每行都生效）：

    唐诗 -> https://zh.wikipedia.org/wiki/静夜思
    宋词 -> anki:search:tag:宋词

链接是网址 → 交给系统默认浏览器打开；其它一律当成 Anki 搜索式，
在卡片浏览器里搜出来。支持这些写法：

    anki:search:tag:唐诗     在卡片浏览器搜索（也可以直接写 tag:唐诗）
    anki:tag:唐诗            同上（按标签搜）
    anki:deck:复习::唐诗     搜这个牌组里的卡
    anki:note:1699999999999  直接定位这张笔记

只写链接、不写标签的老写法照样有效（那时标签就是链接本身）；
标签写重复了只留第一条。

制卡不用手写格式：「知识点」字段下面点 [🏷 配置标签链接] 就会
排出这张卡的标签，一行一个输入框：

    [🏷 配置标签链接]  卡片上会显示：唐诗 · 宋词
    唐诗  [ https://...  ] [试打开] [×]
    宋词  [ anki:search:tag:宋词 ] [试打开] [×]
    [🔄 刷新标签]

填完失焦（或按回车）就写回「知识点」字段；[试打开] 当场验链接对
不对；[×] 去掉这一行的链接；标签框里刚加的标签点 [🔄 刷新标签]
就会出来。字段里以前写过的内容（包括老格式）都会保留在面板里。
答案面也有这排标签；手机上（没有插件）网址链接照样能点开。


----------------------------------------------------------
4. 答题界面与评级规则
----------------------------------------------------------
【答对】
    ✅ 回答正确
    [ 困难 Hard ] [ 良好 Good ] [ 简单 Easy ]

    点哪个就按哪个评级。也可以直接用键盘 2 / 3 / 4。

【答错 / 不知道】
    ❌ 回答错误 —— 这题记为「重来」
    解析：……
    解题技巧：……
    [ 继续（记为重来） ]

    答案不再单独列一行（1.1.5 起）：
      · 选择题 / 判断题：绿色 = 该选的那项，红色 = 你选错的那项
      · 填空题：标准答案直接写进原来的空里，答错时还会把你
        自己填的划掉（南京 → 北京），没填就只写标准答案

    默认会先把这些和解析亮出来，你看完点「继续」，
    这张卡才被记为「重来」。

    如果想要答错立刻翻页、什么都不显示，去「设置与统计」
    窗口的说明里找到那项配置（在 Anki 自带的插件配置里，
    把 wrong_action 改成 immediate）。

【多选漏选】（需要在设置里打开）
    ⚠️ 漏选 —— 这题只能记为「困难」
    [ 困难 Hard ] [ 还是重来 Again ]

    只有"漏选、但没选错"才算漏选；只要选错了一个，就是
    答错，照样记「重来」。

【关于空格键】
    在答题界面按空格会翻到背面 —— 那是 Anki 原本的
    "显示答案"行为，不是插件的问题。背面也是同一套呈现
    （选择 / 判断靠选项着色，填空把答案写进空里，再加上
    解析 + 解题技巧 + 来源），可以正常按 1/2/3/4。
    直接翻背面不算作答，也不会被计入统计。


----------------------------------------------------------
5. 设置与统计窗口
----------------------------------------------------------
入口：[工具] -> [互动答题卡：设置与统计…]
窗口里有两个标签页：设置、统计。


5.1 设置页（4 个选项）
----------------------------------------------------------
■ 记录作答明细
    统计功能的总开关。默认【开】。
    关掉后不再收集新数据，已有记录保留。

■ 明细保留天数
    默认 0 = 永久保留。
    填 30 就只留最近 30 天，更早的自动清理。

■ 答题时显示本题计时
    默认【关】。打开后卡片右上角显示本题已用时间。
    不论开关如何，统计里的"平均用时"都会记录。

■ 多选题漏选时，允许记为「困难」
    默认【关】。打开后，多选漏选可以记困难，
    但仍然不能记 良好 / 简单。

底部还有：
    [恢复默认]  把这 4 项恢复成默认值（要点保存才生效）
    [保存设置]  写入配置
    [关闭]      关掉窗口

「维护」区还有两个兜底按钮：
    [创建 / 更新题型模板]   题型模板每次启动 Anki 会自动
                            更新，这个按钮是手动兜底
    [生成 3 张示例卡片]     生成示例到「答题卡示例」卡组

其余选项（答错后是否先显示答案、打乱选项、填空是否忽略
标点等）在 [工具] -> [插件] -> 互动答题卡 -> [配置] 里，
两边改的是同一份配置。


5.2 统计页
----------------------------------------------------------
一张卡片级的统计表，可以按条件组合筛选：

    牌组    选某个牌组时，包含它的子牌组
    题型    单选 / 多选 / 判断 / 填空
    标签    集合里的标签（也可以直接输入）
    时间    全部 / 近 7 天 / 近 30 天 / 近 90 天
    关键词  题目文字里包含

表格的列：
    题目 | 牌组 | 题型 | 作答 | 答错 | 正确率 | 难度
         | Anki难易度 | 平均用时 | 最后作答

排序方式（默认"难度 高 → 低"）：
    难度 高 → 低          先做错、反复做错的排最前面
    难度 低 → 高
    Anki 难易度 低 → 高   按 Anki 自己的 ease factor 排

「难度」怎么算的：
    难度 = (答错次数 + 0.5) / (作答次数 + 1)
    也就是平滑之后的错误率，避免"只做过一次刚好做错"
    就直接排第一。显示成百分比。

表格上方一行显示当前筛选条件下的卡片数、总作答次数、
正确率、平均用时。

右下角 [清空统计]：只清空当前用户配置的记录，会二次确认，
清掉就找不回来了。

哪些会被记录？
    只有在答题界面里真正作答过的卡片才算：
    点选项、点提交、点不知道，都会记一条。
    直接按空格翻到背面的不算。
    每次换一张卡，题目一出现就会开始计时。


----------------------------------------------------------
6. 常见问题
----------------------------------------------------------
Q：找不到「互动答题卡」这个题型？
A：先确认插件已加载（工具菜单里能看到「互动答题卡：设置
   与统计…」），然后在窗口的「设置」页点 [创建 / 更新题型
   模板]，再重启一次 Anki。

Q：改了设置/装了新版本但没反应？
A：插件是启动时加载的，必须重启 Anki。

Q：点了选项没反应？
A：多选必须点「提交答案」；单选如果被设成不自动提交，
   也是点「提交答案」。

Q：答错了想自己选「良好」？
A：不行，这是刻意设计的：答错的题只能记「重来」。

Q：统计里没有我刚做的那道题？
A：统计是在 Anki 真正评级的那一刻写入的。如果题目是在
   答题界面里作答的，都会记上；只按空格翻背面不会记。
   另外统计按"用户配置"分开保存，切配置后看到的是另一份。

Q：填空题怎么让每个空各出一张卡？
A：用「互动答题卡·填空」题型，在题目里写 {{c1::答案}}
   {{c2::答案}}……一个 c 号出一张卡（见 3.3）。

Q：编辑器的「选项 / 答案」怎么不见了，变成勾选框了？
A：那是插件给这三个题型做的小控件，改的还是原来的字段内容，
   保存方式不变。别的题型（「问答」「填空」等）完全不受影响。

Q：「用同标签卡片的技巧」点了没反应 / 说我没有标签？
A：先在这张卡的标签框里加标签（敲完按回车），再点那个按钮。
   插件是按标签去找「同标签、写过解题技巧」的其他卡片；如果确实
   没有同标签的卡写过技巧，它会直接告诉你「同标签的卡片里还没有
   解题技巧」。候选列表里不再显示题目，只显示技巧正文和共同标签；
   文字一样的技巧只会出现一条，所以看到「就一条」别奇怪。

Q：「相关知识点」的标签点不动 / 跳错地方？
A：制卡时在「知识点」字段里一行写一条「标签 -> 链接」（写法见 3.6），
   也可以点字段下面的 [🏷 配置标签链接] 逐行填、用 [试打开] 当场验证。
   卡片上只有配了链接的标签才会出现，点标签跳到它自己那条链接。
   （手机上只有网址能直接点开，Anki 搜索式的会显示成「在 Anki 里
   搜：xxx」。）

Q：手机上能刷这些卡吗？
A：能。选项照样点、填空照样填，当场就能看到对错（选项着色、
   填空的答案写在空里）；
   判完之后按手机屏幕下面的「显示答案」，再按 1 重来 / 2 困难 /
   3 良好 / 4 简单 自己评级，排程和电脑上一样。
   区别只有一个：手机上不会自动帮你记「重来」，答错要自己按 1。

Q：手机上怎么制卡？
A：字段就是纯文本：选项一行一个，行首写 * 就是正确项；判断题在
   题目末尾手打 <!--iq-tf:对--> 或 <!--iq-tf:错--> 就行（电脑上
   直接用那个勾选框）。

Q：我发现题目里多了一串 <!--iq-tf:对-->，是什么？
A：那是判断题的答案标记（1.1.3 起不再用「答案」字段，改存这里）。
   卡片上完全看不见，搜索、排序、卷面也不会露出来；想改答案就在
   编辑器里重新勾一下那个勾选框。手滑删掉也没关系，下次启动 Anki
   插件会自动补回来。

Q：统计会不会越攒越大？
A：一条记录很小，正常使用可以忽略。担心的话把「明细保留
   天数」设成 90 之类，或者定期点 [清空统计]。
